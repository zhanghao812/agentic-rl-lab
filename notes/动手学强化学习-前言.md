# 《动手学强化学习》前言笔记

> 来源：[《动手学强化学习》前言](https://hrl.boyuai.com/chapter/intro/)
> 范围：链接对应的前言页；下方学习建议为补充整理，不代表全书逐章笔记。

## 1. 核心观点

强化学习的学习需要把理论与编程实验结合起来：理解公式后，还要通过实现、调试和对比实验观察算法行为。

## 2. 为什么学习强化学习

- 人工智能的需求从检测、预测进一步延伸到决策。
- 强化学习可用于机器人、游戏、推荐、能源优化等场景。
- 系统学习的困难之一，是理论教学与实际编程之间存在距离。

## 3. 为什么强调“动手”

- 强化学习涉及较复杂的数学，仅阅读推导不易形成直观认识。
- 前言以 Q 学习为例：价值高估及双 Q 方法的改善效果，更适合通过实验对比理解。
- 教材采用 notebook 将原理、公式与可运行代码结合，支持边学边修改和验证。

## 4. 全书学习路线

根据页面导航，可按以下顺序学习：

1. **基础**：多臂老虎机、马尔可夫决策过程、动态规划、时序差分、Dyna-Q。
2. **进阶**：DQN、策略梯度、Actor-Critic、TRPO、PPO、DDPG、SAC。
3. **前沿**：模仿学习、模型预测控制、基于模型的策略优化、离线强化学习、目标导向与多智能体强化学习。

## 5. 我的实践清单（补充建议）

每学习一个算法，完成以下闭环：

- [ ] 用自己的话解释：算法解决什么问题？
- [ ] 写出关键变量、更新公式及其含义。
- [ ] 跑通最小示例，记录环境、参数和随机种子。
- [ ] 每次只改变一个因素，观察奖励曲线与训练行为。
- [ ] 对照基线，记录改善、退化以及可能原因。
- [ ] 记录失败案例和仍未理解的问题。

## 6. 复习问题（补充）

1. 检测、预测和决策任务分别输出什么？
2. 为什么“看懂公式”不等于“理解算法行为”？
3. 如何设计实验，检查 Q 值是否出现高估？
4. 比较两个算法时，应控制哪些实验条件？

## 一句话记忆

学习强化学习：理解原理 → 实现算法 → 观察实验 → 回头修正理解。
